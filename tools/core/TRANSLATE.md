# core menu ("The Core Truth of the Urantia Book", Jay Han): translation brief (es / fr / pt)

Read `../SPEC_AM.md` first; everything there applies. Folder: `E:\OneDrive\내 문서\유란시아\urantiaamerica 홈페이지\tools\core\`.
The English edition you are translating (read only, to see how it looks): `E:\OneDrive\내 문서\유란시아\urantiafareast 홈페이지\site\core-en\index.html`.
It is a one-file digital reader: 52 short study chapters by Jay Han, each paragraph full of clickable references `[P:S.p]` that open the
book text in a pop-up. You translate **only the 52 chapters and the screen text (UI)**. The book text in the pop-up, the paper reader and the
passage search come automatically from the official translation (`tools/data/<l>.json`, `<l>_titles.json`).
Menu name on the home page (already fixed in `site/i18n.js`): es *Lo esencial de El libro de Urantia* · fr *L’essentiel du Livre d’Urantia* ·
pt *O essencial de O Livro de Urântia*.

- `<l>/cNN.json`: **your output**, a JSON object with exactly the same keys and every value translated (a string).
  Write it from a Python script with `json.dump(D, open(path, "w", encoding="utf-8"), ensure_ascii=False, indent=1)`.
  Never put non-ASCII text in a shell heredoc. Keep your own scripts only in `scratch/<l>_cNN/` (create it; nobody else uses it).
  Work in parts: load your output file if it exists, add units, dump it again, and save often.
- `work/inline_<l>_cNN.json`: every ⟦Q⟧ quotation of the chunk with the full official verse and, if the aligner found it, the ready official cut (`auto`).
- `work/todo_<l>_cNN.json`: the ⟦Q⟧ quotations the aligner could not cut (you cut them, see below).

  Glossary `../glossary/glossary_<l>.json` = list of [English, official term, definition].

## Unit keys
- `NN.title`: chapter title (sidebar and chapter header; the builder adds the "CHAPTER N" label). NN = 01–52.
- `NN.BBB.h3`: section heading, e.g. `1. The Universal Father: The Origin of All Creation` → keep the number: `1. El Padre Universal: …`.
- `NN.BBB.h4`: sub-heading, e.g. `1) The Absolute Center of All Things` → keep `1) `.
- `NN.BBB.p`: a paragraph (plain text, no HTML).
- The UI keys (no number prefix, chunk c01 only): see "UI strings" below.

## References `[P:S.p]`
- Keep **every** `[P:S.p]` token with the same numbers (ASCII brackets, no space inside). The order may change if the grammar needs it; the checker compares the lists.
- Put the token right after the clause it supports, before the full stop or comma, with one space before it as in the English: `… sustentador infinito [1:0.3].`
- Some paragraphs contain bare numbers that are not links, e.g. `, 3:2.6,` — copy them as they are.

## Urantia Book quotations: never translate them yourself
**Marked quotations** `⟦Q P:S.p⟧ … ⟦/Q⟧` (10 in the whole menu, all in c01–c03). The text between the markers must be the official words of that
verse **character for character** (the checker ignores only whitespace). Keep both markers and the reference inside the opening marker.
- Where `work/inline_<l>_cNN.json` gives an `auto` cut, you may either copy it between the markers or leave the markers **empty**
  (`⟦Q 1:0.3⟧⟦/Q⟧`): the builder then fills them from `auto_<l>.json`. 7 of the 10 are auto-cut in all three languages.
- The 3 in `work/todo_<l>_cNN.json` (23.003.p *the holy mountain of God* [53:1.1], 24.032.p *the fall of man* [75:8.1],
  28.033.p *You are all recipients of my divine power* [131:7.2]) you cut yourself from the verse given in the file
  (e.g. `amq.cut("es", "53:1.1", "el monte", "Dios")`). If the official wording cannot be cut cleanly, take the whole official clause.
  Omissions inside a quotation are written ` … ` (space, U+2026, space).
- Change the quotation marks around the markers: es « », fr « » (normal space inside; the builder makes it no-break), pt “ ”.
  Adjust the sentence around the quotation so that it reads naturally.
**Unmarked phrases in quotes** (about 36, e.g. “God the Son”, “King of Salem”, “Be you perfect” repeated loosely): these are names or loose
quotations and are not checked. Translate them with the official terms; where the verse in `work/phrases_<l>_cNN.json` has an obvious
official wording for the phrase, use that wording. Same quotation marks as above.

## Style
- The author is Jay Han. Tone: a plain, explanatory study guide, not a sermon. Faithful, natural standard written language; same content and order; add nothing, drop nothing.
- Book title in prose: es *El libro de Urantia*, fr *le Livre d’Urantia*, pt *O Livro de Urântia* (plain text, no Markdown, no HTML).
- es neutral Spanish (readable in Latin America; *vosotros* only inside official quotations). fr 1990 reformed spelling as the official text
  (maitre, ile, connaitre, paraitre); « » with a normal space inside and a normal space before ; : ! ? (the builder makes them no-break; never inside ⟦Q⟧).
  pt Brazilian spelling **as the official text** (old orthography: idéia, conseqüência, freqüente, assembléia, heróico — check doubtful words with amq).
- Keep URLs as they are (`cafe.naver.com/urantiastudykorea`, `blog.naver.com/trusteen`). No Korean anywhere; no English left except names and URLs.
- Large numbers follow the language's own scale and decimal comma (pt trilhão = 10^12; fr billion = 10^12; es billón = 10^12).
